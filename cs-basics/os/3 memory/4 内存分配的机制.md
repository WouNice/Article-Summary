# 内存分配的机制

## 内存分配的基本类型

### (1) 静态内存分配

**原理**：在编译时确定内存布局，程序运行前分配固定大小的内存区域。

特点：

-   确定性高：无运行时分配开销，适合硬实时系统。

-   无碎片风险：但灵活性差，未使用的内存无法回收。

应用场景：RTOS中的任务栈、硬件寄存器映射。

### (2) 动态内存分配

**原理**：运行时按需申请和释放内存，分为**堆分配**和**内存池**。

特点：

-   灵活性高：适应多变的内存需求（如malloc）。

-   碎片风险：频繁分配/释放可能导致内存碎片。

## Linux内存分配机制

(1) 虚拟内存管理

-   分页机制：将物理内存划分为4KB页，通过页表映射到进程的虚拟地址空间。
-   动态扩展：用户态通过brk（扩展堆）或mmap（映射匿名内存）申请内存。

(2) 内核态分配器

-   `kmalloc`：分配物理连续内存，适合DMA操作，但易碎片化。
-   `vmalloc`：分配虚拟连续但物理不连续的内存，适合大块内存。
-   Slab分配器：高效管理内核对象（如inode），减少小内存分配开销。

(3) 用户态分配器

-   `malloc/free`：依赖glibc实现，底层调用brk或mmap。
-   优化技术：
    -   写时复制（COW）：父子进程共享内存，写入时复制。
    -   Swap交换：物理内存不足时，将不活跃页写入磁盘。
