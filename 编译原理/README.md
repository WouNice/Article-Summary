# 编译原理：从入门到实战 🚀

**适合读者**：对编译器如何工作感到好奇的开发者、计算机专业学生、想要自己动手写一个小型编译器的朋友。

**前置知识**：C 语言基础（能看懂结构体和指针即可）、基本的数据结构（树、栈、哈希表）。

## 📖 学习路线

```
第1章：编译器到底是什么？  ← 建立直观认识
   ↓
第2章：词法分析           ← 学会"断词"
   ↓
第3章：正则与自动机        ← 词法分析器的理论基石
   ↓
第4章：语法分析（上）      ← 自顶向下解析（递归下降）
   ↓
第5章：语法分析（下）      ← 自底向上解析（LR 族）
   ↓
第6章：语义分析           ← 类型检查与符号表
   ↓
第7章：中间代码           ← 编译器"通用语"IR
   ↓
第8章：代码优化           ← 让程序跑得更快
   ↓
第9章：目标代码生成        ← 最终产出机器码
   ↓
第10章：完整编译器实战      ← 用 C 写一个 TinyC 编译器
   ↓
第11章：高级专题           ← 从理论到工业界的最佳实践
   ↓
第12章：生产案例           ← 真实世界中的编译器
```
